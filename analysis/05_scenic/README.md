# SCENIC -- Gene Regulatory Network Inference

Gene regulatory network analysis using [pySCENIC](https://github.com/aertslab/pySCENIC), including sex-stratified regulon activity comparison in Alzheimer's disease.

## Workflow

Per cell type (Fig. 5 prior GRN): `00a_pyscenic_per_celltype.py <CellType>` (loom -> grn -> ctx -> aucell).

Sex-stratified (Fig. 6c-d): `00b_pyscenic_grn_sex_stratified.py` (loom -> grn) -> `01_filter_adjacency_noncoding.py` -> `scenic_ctx_aucell_viz.py` (ctx -> aucell -> plots) -> `sex_scenic_heatmaps_networks.py` / `sex_scenic_igraph_networks.py`.

GRNBoost2 (`pyscenic grn`) is stochastic and was not seeded in the original runs, so reruns reproduce the networks approximately rather than edge-for-edge.

## Scripts

| Script | Description |
|--------|-------------|
| `00a_pyscenic_per_celltype.py` | Per-cell-type pySCENIC: splits a cell type by diagnosis, writes looms, runs `pyscenic grn`, `ctx` (`--mask_dropouts`) and `aucell`. The Dementia-group regulons are the prior GRN refined by NetREm for Fig. 5. |
| `00b_pyscenic_grn_sex_stratified.py` | Looms and `pyscenic grn` for the six sex x diagnosis groups. |
| `01_filter_adjacency_noncoding.py` | Removes non-coding / provisional target symbols from the sex-stratified adjacency lists before `ctx`. **Known issue:** its pseudogene rule (`P\d+$`) also removes protein-coding targets ending in P+digits (e.g. SNAP25, AQP4, PLP1, FOXP2); kept as-is to reproduce the published regulons, with a `STRICT_PSEUDOGENE_RULE` switch to restrict it. |
| `scenic_ctx_aucell_viz.py` | pySCENIC ctx (regulon prediction) and AUCell (cellular enrichment), UMAP, heatmaps, and Z-score clustermaps for six sex-diagnosis groups. |
| `scenic_regulon.py` | Regulon Z-score computation and UMAP visualization for microglia. |
| `sex_scenic_heatmaps_networks.py` | Male vs Female comparison: per-cell-type regulon heatmaps, differential regulon analysis (M-F), and TF-TG networkx plots. |
| `sex_scenic_igraph_networks.py` | TF-TG heatmaps and igraph network visualizations with sex-specific edge identification and optional GWAS gene highlighting. |
| `regenerate_network_figures_fig5.py` | Per-cell-type (AST, EXC, INH, MIC, ODC) TF-TG network figures combining pySCENIC's prior GRN with NetREm's TF-TF cooperative/antagonistic classification -- this is the analysis underlying Fig. 5. |
| `combined_heatmap_fig5.py` | Combines the per-cell-type outputs of `regenerate_network_figures_fig5.py` into the unified Fig. 5 heatmap panel. |

**Important -- external data dependency:** `regenerate_network_figures_fig5.py` and `combined_heatmap_fig5.py` consume NetREm's already-computed TF-to-TG output tables (`NetREm_TF_to_TG_regulatory_network_links_..._bySaniya_Final.csv`, one per cell type) as plain input data -- they do not run NetREm's regression itself. **NetREm's implementation is not included in this repository**: NetREm was run by S. Khullar (co-author) using the separately published NetREm method ([github.com/SaniyaKhullar/NetREm](https://github.com/SaniyaKhullar/NetREm)), and its run scripts are not part of this repository; these two scripts are only runnable once those TF-TG CSVs are placed in `data/scenic/netrem_tables/` (see the Data section of the main README).

## Inputs

- pySCENIC adjacency CSVs and loom files
- Ranking database: `hg38__refseq-r80__500bp_up_and_100bp_down_tss.mc9nr.genes_vs_motifs.rankings.feather`
- Motif annotations: `motifs-v9-nr.hgnc-m0.001-o0.0.tbl`
- GWAS gene list: `gwas_genes_ad_ftd.xlsx` (optional)
- Sex-stratified h5ad files
- `data/scenic/netrem_tables/NetREm_TF_to_TG_regulatory_network_links_..._bySaniya_Final.csv` (one per cell type; external, not generated by this repo -- see note above)

## Outputs

- Regulon CSVs and AUCell matrices per group
- Regulon Z-score heatmaps and UMAP plots
- TF-TG network plots (per-sex and comparison)
- Sex-specific edge tables
- `figures/scenic_v11_nature/` -- per-cell-type and combined Fig. 5 network figures
